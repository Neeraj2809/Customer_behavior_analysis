# 🛍️ Customer Shopping Behavior Analysis

An end-to-end **Data Analytics Project** exploring customer purchasing patterns, spending behavior, product preferences, customer segmentation, and subscription trends using Python, PostgreSQL, and Power BI.

## 📌 Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases across different product categories**.

The objective is to extract meaningful business insights by performing Exploratory Data Analysis (EDA), cleaning and transforming data, writing SQL queries, and developing an interactive Power BI dashboard.

The analysis focuses on understanding customer spending patterns, identifying popular products, evaluating discount strategies, and comparing subscriber and non-subscriber behavior.

## 📂 Dataset

The dataset contains **3,900 rows and 18 columns**.

**Key Features:**
- Customer Demographics: Age, Gender, Location, Subscription Status.
- Purchase Details: Item Purchased, Category, Purchase Amount, Season, Size, Color.
- Shopping Behavior: Discount Applied, Promo Code Used, Previous Purchases, Purchase Frequency.
- Customer Feedback: Review Rating.
- Delivery Information: Shipping Type.

**Data Quality:**
- 3,900 records.
- 18 original columns.
- 37 missing values in the Review Rating column.

## 🔄 Project Workflow

### 1. Data Loading & Exploration – Python

- Imported the dataset using Pandas.
- Examined the first few records using `head()`.
- Checked data types and structure using `info()`.
- Generated summary statistics using `describe()`.
- Identified missing values and explored data distributions.

### 2. Data Cleaning & Transformation – Python

- Handled 37 missing values in the Review Rating column using the median rating of each product category.
- Standardized column names into snake_case format.
- Renamed columns for better readability.
- Created an `age_group` column to categorize customers.
- Created `purchase_frequency_days` by converting purchase frequencies into numerical days.
- Checked redundancy between `discount_applied` and `promo_code_used`.
- Removed the redundant `promo_code_used` column.

### 3. Database Integration – PostgreSQL

- Connected Python to PostgreSQL using SQLAlchemy and psycopg2.
- Loaded the cleaned dataset into a PostgreSQL database.
- Stored the data in a table named `customer`.
- Prepared the database for structured SQL analysis.

### 4. SQL Analysis – PostgreSQL

Performed SQL queries to answer important business questions:

1. **Revenue by Gender:** Compared total revenue generated by male and female customers.
2. **High-Spending Discount Users:** Identified customers who used discounts but still spent above the average purchase amount.
3. **Top 5 Products by Rating:** Identified products with the highest average review ratings.
4. **Shipping Analysis:** Compared average purchase amounts between Standard and Express shipping.
5. **Subscription Analysis:** Compared average spending and total revenue between subscribers and non-subscribers.
6. **Discount-Dependent Products:** Identified the five products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments based on previous purchases.
8. **Top Products by Category:** Identified the top three most purchased products within each category.
9. **Repeat Buyers Analysis:** Examined subscription behavior among customers with more than five previous purchases.
10. **Revenue by Age Group:** Calculated the revenue contribution of different customer age groups.

### 5. Dashboard Development – Power BI

Developed an interactive Power BI dashboard to visualize key business metrics and analytical findings.

The dashboard helps understand:
- Customer purchasing patterns.
- Revenue distribution.
- Product and category performance.
- Customer segmentation.
- Subscription trends.
- Discount and shipping behavior.

### 6. Reporting & Presentation

- Created a project report documenting the complete analytical process, SQL analysis, and business recommendations.
- Prepared an executive presentation using Gamma to communicate key findings and recommendations in a structured, visual format.

## 📊 Key Results & Business Insights

The analysis revealed several interesting findings:

| Metric | Result |
|---|---:|
| Total Purchases | 3,900 |
| Average Purchase Amount | $59.76 |
| Average Review Rating | 3.75 |
| Loyal Customers | 3,116 |
| Returning Customers | 701 |
| New Customers | 83 |
| Subscribers | 1,053 |
| Non-Subscribers | 2,847 |

**Key Insights:**

- **Gender & Revenue:** Female customers generated approximately $75,191, while male customers generated approximately $157,890.
- **Discount Behavior:** Identified 839 customers who used discounts but still spent above the average purchase amount.
- **Shipping Preferences:** Express shipping customers had a slightly higher average purchase amount ($60.48) than Standard shipping customers ($58.46).
- **Customer Segmentation:** Loyal customers represented the largest segment, with 3,116 customers.
- **Product Performance:** Gloves, Sandals, Boots, Hat, and Skirt were among the top-rated products.
- **Discount Trends:** Hat, Sneakers, Coat, Sweater, and Pants had the highest discount rates.
- **Subscription Behavior:** Non-subscribers generated higher overall revenue due to their larger customer base.

- Introduce loyalty programs to encourage repeat purchases.
- Optimize discount strategies to balance sales growth and profit margins.
- Highlight top-rated and best-selling products in marketing campaigns.
- Use customer demographics and purchasing behavior for targeted marketing.

## ⚙️ How to Run the Project

### Prerequisites

Install the following:
- Python 3.x
- Jupyter Notebook
- PostgreSQL
- pgAdmin (optional)
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone <your-github-repository-url>
```

```bash
cd Customer-Shopping-Behavior-Analysis
```

### Step 2: Install Required Libraries

```bash
pip install pandas numpy sqlalchemy psycopg2-binary jupyter
```

### Step 3: Load the Dataset

Place `customer_shopping_behavior.csv` in the project directory.

Open the Jupyter Notebook:

```bash
jupyter notebook
```

Run `Customer_Shopping_Behavior_Analysis.ipynb` to perform data exploration, cleaning, transformation, and database integration.

### Step 4: Configure PostgreSQL

1. Create a PostgreSQL database named `customer_behavior`.
2. Update the database connection settings in the notebook.
3. Run the database integration section to load the cleaned dataset into the `customer` table.

**Security Note:** Use environment variables for database credentials instead of hardcoding passwords in the notebook.

### Step 5: Execute SQL Queries

Open `customer_behavior.sql` in pgAdmin or another PostgreSQL-compatible SQL editor.

Execute the queries to explore customer behavior and generate business insights.

### Step 6: Open the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` using Power BI Desktop.

Connect or update the data source if required to explore the interactive dashboard.
